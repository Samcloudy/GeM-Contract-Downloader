GeM Contract Downloader

Bulk-download Government e-Marketplace contract PDFs

Python Tool · Local-Only

What this does

A Python-based automation tool that downloads GeM contract documents in bulk — either by category + date range, or by a list of contract numbers. It runs entirely on your own machine; no data leaves your computer.

✓Two modes: search by category or upload a contract list
✓Live progress log and file listing in the browser
✓Automatic CAPTCHA handling
✓Runs on 127.0.0.1 — completely private

Run it locally

GitHub Pages can't run Python, so this page is just a description. To use the actual tool, clone the repo and run it:

git clone https://github.com/Samcloudy/GeM-Contract-Downloader.git
cd GeM-Contract-Downloader
pip install -r requirements.txt
python app.py

Then open http://127.0.0.1:5000 in your browser.
